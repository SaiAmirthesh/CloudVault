# Frontend Engineering & Design Code of Conduct

The agent must enforce the following strict execution guardrails under all circumstances throughout the lifecycle of this build process.

## 1. Absolute Design Constraints
* [cite_start]**The Vibe Coder Formula:** Every new block or layout variant built must clearly state its composite structure blending 1 explicit Structural Layout pattern, 1 Visual Aesthetic style guide, and exactly 1 motion animation target context[cite: 8].
* [cite_start]**Color Control Discipline:** Never break the 60-30-10 distribution rule[cite: 579]. [cite_start]Do not randomly introduce secondary decorative brand accents across layouts unless they have clear system mapping utility[cite: 584, 592].
* [cite_start]**Typography Balance:** Typography sizing choices must follow an explicit mathematical scale multiplier based off a clear root definition variable[cite: 541, 546]. [cite_start]Tighten letter spacing exclusively on oversized display components (`-0.03em` to `-0.05em`); never allow loose alignment defaults on headers[cite: 624].

## 2. Animation & UX Rules
* [cite_start]**Accessibility First:** Do not compromise interface accessibility for low-contrast trends[cite: 45]. [cite_start]Neumorphic tactile button styles must be isolated exclusively to high-context dashboard elements or low-priority utility widgets; critical calls to action must maintain high contrast ratios[cite: 44, 45].
* [cite_start]**Performance Optimization:** All scroll tracking components must run inside low-overhead animation contexts or leverage native GPU acceleration targets (`transform: scaleX()`, `translateY()`)[cite: 264, 278, 279].
* [cite_start]**Lenis Exclusion Zones:** Never bind momentum-smooth scroll tracking environments across active modals or isolated overflow areas (`overflow: hidden`), to protect user coordinate focus[cite: 285].

## 3. Code & Semantic Deliverables
* [cite_start]**Semantic Foundations:** Use exact semantic tags (`<nav>`, `<main>`, `<dialog>`, `<ol>`) for layout building rather than nesting multiple layout blocks within unformatted structural divisions[cite: 497, 500].
* [cite_start]**State Transparency:** Active tab adjustments must map visibility settings through native state declarations or standard inline conditional bindings (`display: none` / `display: block`)[cite: 515, 516]. [cite_start]Ensure interactive indicators translate across layouts dynamically[cite: 521].
